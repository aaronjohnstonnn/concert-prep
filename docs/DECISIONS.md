# Technical and Product Decisions



## Decision: Start with an artist-search MVP

**Date:** 7 October 2026  
**Decision:** Build artist search and track ranking before concert discovery or AI features.  
**Reason:** It creates the core product loop and lets me learn APIs, frontend development, and backend development without becoming overwhelmed.  
**Trade-off:** The app will not initially show concerts or multi-artist lineups.



## Decision: Use Next.js and TypeScript

**Date:** 7 October 2026  
**Decision:** Use Next.js with TypeScript as the initial stack.  
**Reason:** It supports both frontend and backend development in one project and provides useful type safety while I learn.  
**Trade-off:** I will need to learn React, Next.js routing, server-side concepts, and TypeScript.



## Decision: Use a scoring algorithm before AI

**Date:** 7 October 2026  
**Decision:** Begin with a transparent recommendation scoring algorithm rather than generative AI.  
**Reason:** It is easier to test, debug, explain, and improve.  
**Trade-off:** Early recommendations may be less personalised.
